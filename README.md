# Lightweight Cloud CRM

Это CRM для работы с клиентами, сделками и командой внутри компании с оплатой в крипте.

## Для чего подходит приложение

Система помогает:

- вести базу контактов
- создавать и сопровождать сделки
- двигать сделки по этапам воронки
- ставить задачи по сделкам
- следить за аналитикой продаж
- управлять участниками компании и их ролями
- принимать приглашения в компанию прямо внутри приложения

## Основные разделы

### Дашборд

На дашборде собрана краткая сводка по текущей работе:

- количество сделок
- активность менеджеров
- основные показатели по воронке
- быстрый обзор текущей компании

### Воронка

Во вкладке `Воронка` можно:

- добавлять новые сделки
- видеть сделки по этапам
- открывать подробности по каждой сделке
- смотреть закрытые сделки
- читать историю по сделке
- работать с задачами, связанными со сделкой

Если у пользователя роль менеджера, он видит только свои сделки.

### Контакты

Во вкладке `Контакты` хранится клиентская база.

Там можно:

- добавлять новые контакты
- редактировать данные контакта
- хранить email, телефон, компанию и должность
- использовать контакты при создании сделок

### Аналитика

Раздел `Аналитика` показывает:

- конверсию по этапам
- эффективность работы менеджеров
- средний чек
- прогноз по выручке
- общую динамику работы с воронкой

### Компания

Во вкладке `Компания` можно:

- создать компанию
- переименовать компанию
- удалить компанию
- приглашать сотрудников на роли
- просматривать участников компании
- менять роли участников
- удалять участников из компании
- видеть журнал изменений по доступам

Если пользователь ещё не состоит ни в одной компании, он может создать новую компанию или дождаться приглашения.

## Роли в системе

В приложении есть роли:

- `Владелец`
- `Администратор`
- `Менеджер`
- `Наблюдатель`

### Владелец

Может полностью управлять компанией, сотрудниками и всеми данными CRM.

### Администратор

Может управлять доступами и данными CRM, но не заменяет владельца.

### Менеджер

Работает со своими сделками, контактами и задачами.

### Наблюдатель

Имеет доступ только на просмотр.

## Приглашения в компанию

Приглашения приходят не по почте, а прямо внутри приложения.

Пользователь:

- входит в систему
- видит входящее приглашение
- подтверждает его
- получает доступ к компании и своей роли

Пользователь не может одновременно быть назначен в несколько компаний.

## Пробный период и оплата

У каждого пользователя есть пробный период.

Во вкладке `Настройки` можно:

- увидеть статус доступа
- посмотреть дату окончания доступа
- посмотреть данные по последнему платежу
- перейти к оплате через PAYMENTO

Если пробный период или оплаченный срок закончился, приложение направляет пользователя в настройки для продления доступа.

## Как обычно работают в системе

Обычный сценарий выглядит так:

1. Пользователь входит в систему.
2. Получает доступ к компании или создаёт новую.
3. Добавляет контакты.
4. Создаёт сделки.
5. Двигает сделки по этапам воронки.
6. Ставит задачи по сделкам.
7. Следит за закрытыми сделками и аналитикой.

## Что важно помнить

- каждая компания работает в своём отдельном пространстве
- участники и данные одной компании не смешиваются с другой
- приглашения подтверждаются внутри приложения
- после окончания доступа нужно продлить подписку в настройках
